# Laboratorio BDP v7 en la nube (GitHub Codespaces)

Laboratorio de Big Data del Dr. Abel Coronado: HDFS, Spark 4.1, Sedona, Elasticsearch y JupyterLab, listos en el navegador. Es el mismo laboratorio de la versión portable BDP v7.

[![Abrir en GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/abxda/bdp-lab-nube?quickstart=1)

1. Inicia sesión en GitHub y pulsa el botón de arriba (máquina de 4 núcleos).
2. Sigue el archivo `LEEME.md`, que se abre solo.

- **Qué contiene:**
  - `bdp_start.py` descarga el laboratorio BDP v7 de Linux y verifica su sha256 contra el manifiesto publicado.
  - `notebooks/` trae los cuadernos de las Semanas 2 a 4.
- **Datos:** recorte de Aguascalientes (INEGI) publicado en Hugging Face (`abxda/bdp-lab`, `v7/datos/estados/01/`).
- **Costo:** usa tu cuota gratuita de Codespaces (120 horas-núcleo al mes; 180 con GitHub Student Pack).
